# CIA Triad in DevOps and Cloud

## Confidentiality
Ensures data is accessible only to authorized users.

### DevOps Examples
- GitHub Secrets
- AWS Secrets Manager
- Encrypted environment variables

## Integrity
Ensures data and code are not altered without authorization.

### DevOps Examples
- Git commit history
- Image signing for Docker containers
- Hash validation in CI/CD pipelines

## Availability
Ensures systems and services are always accessible.

### DevOps Examples
- Load balancers
- Auto-scaling groups
- Kubernetes self-healing pods
